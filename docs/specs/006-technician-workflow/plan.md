# Načrt

1. Po commitu dodelitev ustvari ločeno odvisno vejo.
2. Razširi model poročil in označevanje nadaljnjega posega, brez brisanja starih podatkov.
3. Dodaj dodeljeno podrobnost elektrarne in pet zadnjih posegov z deli.
4. Poenoti API osnutka/urejanja/oddaje z avtorstvom trenutnega vodje.
5. Zaklepanje poročila, zaključek servisa/zahtevka in obvestila združi v transakcijo.
6. Poveži strukturirana UI polja, zgodovino, potrditve in skupno poročilo vodje.
7. Testiraj mejne vnose, člane in tujce, sočasno oddajo in nadaljnji poseg.
8. Preveri celotno aplikacijo v lokalnem browserju; lint, testi in build obeh delov.
9. Lokalno dokumentiraj in commitaj; uporabnik opravi push.
