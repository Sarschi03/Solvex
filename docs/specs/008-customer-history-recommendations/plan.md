# Načrt

1. Uvesti neobvezen javni povzetek in trajno nastavitev priporočil brez spremembe internih poročil.
2. Dodati lastniški API ter povezati stran zgodovine z izbiro elektrarne.
3. Izračunati letni cikel samo iz opravljenih rednih pregledov in dodati obvestila.
4. Povezati stran priporočil z izklopom in preveriti vloge, datume ter zasebnost.
5. Lint, testi, gradnja obeh delov; ločen slovenski commit pred administracijo.
